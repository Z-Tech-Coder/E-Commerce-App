# 🛒 E-Commerce Application

A full-stack **multi-vendor E-Commerce application** built with **React** and **Spring Boot**.

> **This project is developed for learning purposes.** It serves as a hands-on way to practice software engineering concepts, explore new technologies, and improve my development skills. As I learn new concepts and best practices, I continuously update and refactor this project.

## 🎯 Purpose

This repository is intentionally public in the hope that it can help other students and developers who are learning full-stack development, object-oriented design, and software architecture. Feel free to explore the code, learn from it, or suggest improvements.

## 🚀 Features

### Customer
- Browse, search, and filter products
- Add products to a shopping cart
- Place orders and checkout
- View current and previous orders
- Track deliveries
- Review purchased products
- Submit complaints

### Vendor
- Manage products
- Manage inventory
- View product reviews
- View customer complaints
- Track product revenue

### Administrator
- Monitor platform and vendor revenue
- Search orders
- Manage complaints
- Suspend fraudulent vendors
- Disable products that violate marketplace policies
